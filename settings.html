About
IOCulus v1.0.0
A browser extension for cybersecurity analysts. Right-click any selected text (IP, domain, URL, hash, email) to trigger reputation lookups across VirusTotal, AbuseIPDB, and Shodan.

Free APIs used (no key needed):
• ip-api.com — IP geolocation & ASN
• whoisjson.com / rdap.org — WHOIS lookups

API keys are stored in chrome.storage.sync and synced across your Chrome profile. They are never sent to any server other than the respective API endpoints.
